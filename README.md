# U-Write

Личная мастерская писателя для Windows: главы и сцены, персонажи, мир, события, идеи и комментарии рядом с рукописью.

**[Скачать U-Write для Windows x64](https://github.com/u-lite/u-write/releases/latest)**

В выпуске выберите файл `U-Write-<версия>-Setup.exe`. Установщик проверит наличие WebView2; для его загрузки при необходимости потребуется интернет. Node.js и Rust не нужны. Книги хранятся на вашем компьютере, работа с ними доступна офлайн.

При первом запуске вас встретит книга «Первые строки»: короткое обучение прямо в редакторе. Её можно изменять или удалить как любой другой проект.

Обновления загружаются в фоне и устанавливаются только по кнопке «Обновить и перезапустить», после сохранения книги. Проверку можно отключить в настройках. Программа не отправляет рукописи на сервер.

0.5.5 — Tab для отступов, переименование сцены по всей плашке и защита её границ от случайного стирания. Кнопка × удаляет только разделитель, сохраняя текст. Добавлены локальные русские синонимы через меню правой кнопки мыши и образцы шрифтов в настройках. Синонимы пока экспериментальные: варианты могут быть неточными, контекст предложения не анализируется. Функция отключается в настройках → «Письмо».

Новая установка предлагает Program Files, обновление сохраняет прежнюю папку программы. Установщик запрашивает права администратора.

Пока у программы нет сертификата издателя Windows, поэтому возможно системное предупреждение о неизвестном приложении. Для первых проверок используйте учебную книгу или копию своей рукописи. Пользователю нужен только EXE; файл `latest.json` предназначен для системы обновлений и содержит подпись пакета.

Этот репозиторий предназначен для готовых выпусков и их описаний. Исходный код приложения здесь не публикуется. Автоматически созданные GitHub архивы `Source code` содержат только файлы этого репозитория; для установки используйте EXE.

Сведения о сторонних компонентах включены в установщик и находятся в `ThirdPartyLicenses.txt` рядом с установленной программой. Ошибки можно описывать в [Issues](https://github.com/u-lite/u-write/issues), указав версию программы и последовательность действий. Не прикладывайте личные рукописи без необходимости.
