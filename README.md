# U-Write

Место для вашей истории.

U-Write — программа для писателей на Windows. Здесь можно писать книгу, продумывать персонажей и мир, собирать идеи и держать всё необходимое рядом с рукописью.

**[Скачать U-Write для Windows](https://github.com/u-lite/u-write/releases/latest)**

- Пишите и редактируйте текст, разделяйте книгу на главы и сцены, добавляйте иллюстрации.
- Создавайте карточки персонажей со своими полями и шаблонами, добавляйте собственные типы записей мира, сохраняйте заметки и идеи.
- Оставляйте комментарии к рукописи, находите нужные фрагменты и проверяйте орфографию.
- Настраивайте шрифт, цвета интерфейса и холста, вид страницы так, как удобно вам.
- Сохраняйте книгу в DOCX, PDF, EPUB и FB2 или копируйте текст для Фикбука.

Книги хранятся на вашем компьютере. Писать можно без интернета, а автосохранение помогает беречь вашу работу.
